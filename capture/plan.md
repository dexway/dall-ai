# Capture & plan — reference build

Lane: REFERENCE BUILD. Neither sarufi.io nor gorgias.com belongs to the user. Borrowed: section order and
content *categories* from Sarufi; layout/interaction *patterns* from Gorgias. Name, logo, copy, palette,
typefaces and imagery are new. No screenshots, logos, client names or copy from either site are reused.

Working brand name: Ìdáhùn ("answer / response" in Yorùbá) — placeholder, swap anytime.

## Pattern brief — from Sarufi (content structure)
- Hero: what it is + 2 CTAs, then a trust strip
- Platform: channels list / one agent every channel / flow actions / workflows & outcomes
- How it works: describe → build → test → deploy
- Use cases: carousel of agent types (support, booking, payments, survey, ticketing, lead qualification)
- Across devices: chat mockup + feature cards (handoff, buttons/lists)
- Channels detail, outcomes grid, developers (API/webhooks/code sample), pricing, FAQ, footer

## Pattern brief — from Gorgias (UI)
- Full-bleed hero visual with a live AI conversation floating over it
- Frosted-glass chat bubbles; AI reply bubble with a soft glowing outline; product cards inside the chat
- Glass "ask anything" input under the conversation
- Pill eyebrow labels with a dot before section headings
- Bento grid of mixed-size cards; big-number customer stats; dark + light section alternation
- Paired primary/secondary pill CTAs

## Our differentiation (vs Sarufi) — user's own features + angle
1. Agent that SELLS, not just answers: catalogue, bundles, approved discounts, itemised quote, checkout
   with unique order ref, Paystack/Flutterwave links, bank-transfer path.
2. Transfer-receipt verification: customer uploads screenshot → OCR extracts fields → flagged mismatches →
   human approve; never auto-marks paid. (Huge Lagos pain: fake "I don don send am" alerts.)
3. Private business back office per workspace: orders, payments, customers, files, cases, classes/bookings.
4. Agent Identity Studio: name, face, personality, language mix (English/Pidgin/Yorùbá/Igbo/Hausa),
   business's own images.
5. Launch Kit: auto-generated carousels, posters, short clips & WhatsApp status to announce
   "Meet Amaka, our new assistant" — the marketing Sarufi doesn't do.
6. No API keys, simple naira credit plans (credits explained in plain words), live usage meter.
7. Channels: WhatsApp, SMS, USSD, web widget, inbound + outbound voice calls.
8. Flow actions: send message, condition, LLM agent, API call, thread submit, trigger.

Lagos use cases: food vendor orders, salon/clinic bookings, real-estate inspections, lead qualification,
ticketing/events, surveys, logistics tracking, classes/training enrolment.

Palette: deep "midnight lagoon" green-black + warm amber/coral glow (not Gorgias's light/pink, not Sarufi's).
Type: Bricolage Grotesque (display) + DM Sans (body), Google Fonts, OFL.
Stack: single self-contained HTML page, published as an artifact.
Acceptance: user review + check that no Sarufi/Gorgias name, copy, logo, palette or imagery appears.
